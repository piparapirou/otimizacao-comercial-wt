# Otimização Comercial WT

Artefatos criados com o Claude para o projeto **Otimização Comercial WT**. Repositório privado: contém dados internos da empresa.

Cada pasta em `artefatos/` é uma página HTML autossuficiente (abra o `index.html` no navegador). As pastas terminadas em `-design` guardam o código-fonte de um canvas de design do Claude e só são exibidas dentro do Claude.

| Pasta | Artefato | Original no Claude |
|---|---|---|
| `artefatos/calculadora-cbs-ibs` | Calculadora CBS/IBS de Compras | https://claude.ai/artifact/HNz3UcWzm6gBTskVzSvTmy |
| `artefatos/comercial-wt-painel-de-analise` | Comercial WT — Painel de Análise | https://claude.ai/artifact/3bJjdpYghDGLRJza8E7kVm |
| `artefatos/temas-calculadora-cbs-ibs-design` | Temas da Calculadora CBS/IBS (canvas de design, código-fonte) | https://claude.ai/artifact/UhKGGRuWFuiXsyfYoqYux6 |

`docs/` traz as metodologias registradas no projeto e o backup do painel de 01/09/2026.

Observação: páginas que salvam histórico compartilhado ou usam recursos do Claude (ex.: o Painel de Análise Comercial WT) funcionam por completo só dentro do Claude; fora dele abrem em modo de leitura.
